title: "Never assume the host you developed on"
status: "active"
date: "2026-07-25"
---

/tmp writable, launchd present, grok installed, settings inherited from the installing shell — every one of these was true on the Mac and false on HOSTKEY, and each failed as a silent crash loop rather than a clear error. Probe the capability by attempting the exact operation, degrade to the seat you can staff, and say in the status output which host you are on.
