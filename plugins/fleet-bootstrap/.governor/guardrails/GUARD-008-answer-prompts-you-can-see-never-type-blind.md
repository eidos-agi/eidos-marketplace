title: "Answer prompts you can see, never type blind"
status: "active"
date: "2026-07-25"
---

Clearing a blocking prompt is legitimate when the supervisor has positively identified that exact prompt on screen. Sending keys on a timer, or because a session 'seems stuck', would inject text into a live conversation. Match the prompt first; act only on the match.
